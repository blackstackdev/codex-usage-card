# Release scope

6 October 2026 — 0.3.0 public beta.

Intent: give Windows Codex users a quiet desktop view of remaining usage, plus local skill entry points for status and opening the card. User approved GitHub release and MIT licensing after seeing the workflow.

Brick one: existing read-only app-server client and compact widget. No new accounts, billing, hosted infrastructure or model calls. Dependencies are the user's Python/Tk and signed-in Codex executable.

Brick two: contained plugin manifests, relative helper paths, bounded action routing, sanitised failures, MIT documentation and self-contained archives. Preserve the private working prototype and exclude local receipts/settings/auth files from publication.

Brick three: unit/protocol tests, native Tk smoke, extracted paths with spaces, live status and catalog discovery. Clearly scope host-session and manual UI gaps. GitHub public beta is approved; official plugin-directory submission is outside this release route.
